How it works

    
    
      
  1. Whisper (speech-to-text) writes timed lines in the movie’s own language.
    2. 
      
  2. Each line is translated to Hindi with Google Translate (free, needs internet). Only the subtitle text is sent.
    3. 
      
  3. You get <movie>.hi.srt. Put it next to the movie with the same name and your player picks it up.
    4. 
    

    
Tips

    
    
      
  • Use Chrome or Edge on a computer with a graphics card: speech-to-text on the GPU is many times faster than on the CPU.
    • 
      
  • The model downloads once (0.3–2 GB) and is cached for next time.
    • 
      
  • Keep this tab open until it finishes. A 2-hour movie takes about 10 min on a gaming graphics card (large-v3-turbo), under an hour on built-in laptop graphics (small), and hours on the CPU alone.
    • 
      
  • Laptop with two graphics chips? In Windows Settings › System › Display › Graphics, set Chrome or Edge to High performance.
    • 
      
  • Wrong language detected? Pick it under Audio language. Dual-audio file? Pick the track.
    • 
      
  • Already have English subtitles? Drop the .srt to skip speech-to-text. It only takes seconds.
    •
